Beautiful WooCommerce wishlist plugin with advanced features like wishlist sharing, social sharing, QR code, popular products, and more.

== Description ==

WishGlut is a beautiful and feature-rich wishlist plugin for WooCommerce that allows your customers to save their favorite products and come back to them later.

= Key Features =

* Add to wishlist button with customizable styles
* Guest wishlist support (works without login)
* Multiple wishlist support
* Share wishlist via unique link
* Social media sharing (Facebook, Twitter, Pinterest, WhatsApp, Email)
* QR code generation for easy mobile sharing
* Popular products tracking - see what customers wish for the most
* Wishlist counter widget
* Shortcodes for displaying wishlists anywhere
* My Account integration
* AJAX powered - no page reloads

= Wishglut Integration =

WishGlut integrates seamlessly with Wishglut plugin. When both plugins are active, WishGlut settings are available in Wishglut's integration settings, allowing for a unified admin experience.

= Shortcodes =

* `[wishglut_wishlist]` - Display the current user's wishlist
* `[wishglut_counter]` - Display a wishlist counter with item count
* `[wishglut_button product_id="123"]` - Display an add to wishlist button
* `[wishglut_popular limit="10"]` - Display the most wished products
* `[wishglut_shared_wishlist token="xxx"]` - Display a shared wishlist

= Widgets =

* WishGlut Counter - Display wishlist counter
* WishGlut Popular Products - Display most wished products

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wishglut` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Configure the plugin by going to WishGlut > Settings.

== Frequently Asked Questions ==

= Does this work with variable products? =

Yes, WishGlut fully supports WooCommerce variable products. Each variation can be added to the wishlist separately.

= Can guests create wishlists? =

Yes! WishGlut supports guest wishlists. When a guest logs in, their wishlist is automatically merged with their account.

= Can customers share their wishlists? =

Yes, customers can share their wishlists via a unique link. The plugin also supports social media sharing and QR code generation.

= Is this compatible with page builders? =

Yes, WishGlut provides shortcodes that work with any page builder including Elementor, Divi, Beaver Builder, and the WordPress block editor.
